## 🌟 Caratteristiche Principali

- ⚡ **Velocità Istantanea (Astro SSG + Edge CDN)**: Caricamento immediato delle pagine con Core Web Vitals ottimizzati al 100%.
- 📺 **Copertura Completa del Digitale Terrestre e Sky**: Palinsesto aggiornato minuto per minuto per tutti i canali nazionali, tematici, regionali e pay-tv.
- 🖼️ **Artwork & Poster in Alta Definizione (HD)**: Schede arricchite con immagini ufficiali in alta risoluzione per meteo, telegiornali, film e show televisivi.
- 🔴 **Guarda in Diretta Streaming**: Accesso diretto alle piattaforme di streaming ufficiali (*RaiPlay, Mediaset Infinity, La7 Dirette, TV8 Live, Discovery+*).
- 🎬 **Filtri Tematici Dedicati**:
  - 🍿 **[Film Stasera in TV](https://www.intvstasera.it/film-stasera/)** — Tutti i film in prima e seconda serata con trame, anno, genere e locandine.
  - 📺 **[Serie TV Stasera](https://www.intvstasera.it/serie-stasera/)** — Episodi, stagioni e novità del momento.
  - ⏱️ **[Uscite Serie TV & Countdown](https://www.intvstasera.it/uscite-serie-tv/)** — Calendario e timer al secondo per i nuovi episodi e stagioni su Netflix, Prime Video, Disney+, Sky e Apple TV+.
  - 📡 **[Frequenze DTT & Canali TV](https://www.intvstasera.it/frequenze-dtt/)** — Tabella LCN nazionale, multiplex Rai e Mediaset e guida alla risintonizzazione.
  - ⚽ **[Sport Stasera in TV](https://www.intvstasera.it/sport-stasera/)** — Calcio, Serie A, Champions League, Formula 1, MotoGP, Basket e Tennis.
- 📱 **App Mobile Android & iOS Ready**: Esperienza nativa fluida con sincronizzazione e notifiche di promemoria.

## 🛠️ Stack Tecnologico & Architettura

- **Framework**: [Astro 5+](https://astro.build/) in modalità Static Site Generation (SSG) ad alte prestazioni.
- **Styling**: Tailwind CSS v4 moderno, reattivo e ottimizzato con supporto nativo Dark Mode.
- **Database EPG**: PostgreSQL su VPS ad alta affidabilità con indicizzazione full-text e pipeline di import automatizzata.
- **Edge Deployment**: Cloudflare Pages con routing globale a latenza zero.
- **SEO & Structured Data**:
  - Dati strutturati `schema.org` completi: `BroadcastEvent`, `TVChannel`, `Movie`, `TVSeries`, `ItemList`, `FAQPage`, `BreadcrumbList`.
  - Notifiche automatiche in tempo reale tramite **IndexNow** e **Google Indexing API / WebSub**.
  - Sitemap XML dinamica e validazione automatica dei link canonici.

## 🚀 Guida all'Installazione Locale

```bash
# Clona il repository
git clone https://github.com/rovelati/123programmitv.git
cd 123programmitv

# Installa le dipendenze
npm install

# Configura le variabili d'ambiente (.env)
cp .env.example .env

# Avvia il server di sviluppo locale
npm run dev

# Esegui il build statico di produzione
npm run build
```
